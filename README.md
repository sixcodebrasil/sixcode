# SixCode

Site institucional da **SixCode** — tecnologia sob medida para empresas que querem vender melhor, operar com mais clareza e evoluir seus processos.

## O que você encontra aqui

- Apresentação de serviços de desenvolvimento, sites, sistemas e automações.
- Processo de projeto, cases e posicionamento da SixCode.
- Área de contato para agendar uma reunião ou enviar um e-mail.
- Design responsivo, com foco em performance e experiência de navegação.

## Tecnologias

- [Next.js](https://nextjs.org/)
- [React](https://react.dev/)
- [TypeScript](https://www.typescriptlang.org/)
- [Tailwind CSS](https://tailwindcss.com/)
- [Motion](https://motion.dev/)

## Rodando localmente

### Pré-requisitos

- Node.js 20 ou superior
- npm

### Instalação

```bash
git clone https://github.com/sixcodebrasil/sixcode.git
cd sixcode
npm install
```

### Desenvolvimento

```bash
npm run dev
```

Abra [http://localhost:3000](http://localhost:3000) no navegador.

### Build de produção

```bash
npm run build
npm run start
```

## Scripts disponíveis

| Comando | Descrição |
| --- | --- |
| `npm run dev` | Inicia o ambiente de desenvolvimento. |
| `npm run build` | Gera o build otimizado de produção. |
| `npm run start` | Inicia o build de produção localmente. |
| `npm run lint` | Executa a verificação de código. |
